# Memory Game 🎮

A desktop Memory Game made in WPF using C#.

## Features
- Difficulty levels:
  - Easy (4x5)
  - Medium (5x6)
  - Hard (5x8)
- Score system
- Move counter
- Timer
- Leaderboard with saved player stats
- Custom UI with animated card flipping
- Persistent leaderboard using JSON

## Technologies
- C#
- WPF (.NET)
- XAML
- JSON Serialization

## How to Run
1. Download the latest release
2. Extract the ZIP file
3. Run `Memory Game.exe`

## Project Structure
- `Models` → game data classes
- `Views` → screens/pages
- `Controls` → reusable UI controls
- `Assets` → images and resources
